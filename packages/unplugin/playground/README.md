# CSP Plugin Playground

Manual Vite app for `@csp-plugins/unplugin`. Config presets live in `vite.config.ts` (`strict`, `permissive`, `minimal`); pick one with `CSP_CONFIG`.

```shell
pnpm --filter @csp-plugins/unplugin play
# or from this directory:
pnpm dev
pnpm build
pnpm preview
pnpm quick-test
```

Requires the workspace install at the repo root (Node 22.13+, pnpm 12).
